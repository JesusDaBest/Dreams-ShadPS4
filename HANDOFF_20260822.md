# Dreams sculpt-volume handoff — August 22, 2026

This checkpoint preserves both observed `Dreams` (`CUSA04301`) sculpt-volume modes. Neither mode
is a complete fix.

## The two retained modes

The default source path keeps the faster leader-only ordered-count atomic used before this A/B.
Sculpts can remain malformed or incomplete.

The opt-in comparison adds a subgroup control barrier between the elected lane's atomic result and
the following `BroadcastFirst` in compute shader `0x84aa3dc9`:

```text
SHADPS4_DREAMS_SCULPT_LEADER_BARRIER=1
```

That mode made tutorial geometry render more coherently and caused homespace to render additional
objects on the tested machine. It also made edit mode too slow to use. This isolates a real lane
handoff/reconvergence problem, but the control barrier is not a shippable implementation.

The environment variable is read when the shader is compiled. Delete cached shader
`0x0000000084aa3dc9_0.spv` whenever the option is changed, or the prior compiled mode will remain
active.

## Evidence that narrowed the fault

- The captured sculpt vertex boxes are finite and coherent, with eight unique corners per
  instance and sub-micro-unit parallelepiped closure error.
- GPU-visible compact selectors were stable across the capture. `0x800000` is an intentional
  out-of-range sentinel; robust storage-buffer access returns zero. Do not remap that value or
  widen its descriptor.
- The `0x84aa3dc9` writer's returned ordered-count base directly selects the compact record used to
  derive all eight BC3 writes and the R8 volume write sampled by the sculpt fragment shader.
- An earlier branchless comparison kept lanes converged by issuing one real atomic plus 63
  zero-delta atomics. It also improved shapes/colors but caused catastrophic slowdown, explaining
  why all-lane atomics are not viable.
- R8/BC3 aliasing, tile-19 addressing, gather write coordinates, vertex inputs, and the
  `0xce3b8413` fragment raymarch did not provide a stronger visual fault.

## What remains

Find an efficient way to preserve the barrier mode's correct lane handoff without synchronizing
thousands of workgroups or issuing 64 atomics per wave. Full guest `DS_ORDERED_COUNT` logical-wave
ordering, `wave_release`, and `wave_done` behavior remain incomplete and are a separate follow-up.

Do not claim that either the barrier or branchless mode fixes sculpt rendering. They are controlled
A/B evidence for the producer-side fault.
