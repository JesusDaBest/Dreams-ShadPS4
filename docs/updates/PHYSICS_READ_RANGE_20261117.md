# Physics read ranges · November 17, 2026

[Download the graphical launcher](https://github.com/JesusDaBest/Dreams-ShadPS4/raw/refs/heads/main/builds/cusa04301-physics-read-range-20261117/Dreams-graphical-launcher-physics-read-range-20261117.zip). Extract the ZIP and open **shadPS4QtLauncher.exe**.

Dreams can now synchronize just the table read by two known variants of the `e165304b` compute shader. The emulator gets the address and record count from the same data it gives the shader. If a check fails, it scans the full mapped range as before.

The new path activated during the Ancient Dangers wall test. A wall-break FPS improvement has not been established.
