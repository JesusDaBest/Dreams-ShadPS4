**[Download the graphical launcher package](https://github.com/JesusDaBest/Dreams-ShadPS4/raw/refs/heads/main/builds/cusa04301-mip-depth-20261027/Dreams-graphical-launcher-mip-depth-20261027.zip)**

Extract the ZIP, open **shadPS4QtLauncher.exe**, add Dreams and click **Play**.

This keeps the [previous fixes](ARRAY_RANGE_20261026.md) and adds three corrections:

- Reject mip chains longer than the texture's physical dimensions allow, using the existing null-texture fallback.
- Treat reversed array ranges as empty instead of manufacturing a one-layer view. Non-array instruction behavior is preserved.
- Require the correct logical depth when sharing a cached 3D mip. Padded allocations with the same byte size can describe different depths and previously returned incorrect samples.

Valid textures retain their resolution and detail. No FPS or memory-saving improvement is claimed.
