Dreams on shadPS4 - October 25, 2026 shadow update

Extract the whole ZIP, open shadPS4QtLauncher.exe, add your own Dreams game
folder and click Play. The patched core and matching settings are selected
automatically. No command prompt or separate setup script is needed.

This update repairs the tested cube's shadow bounds, flickering and
mid-distance disappearance. Earlier rendering fixes are retained.

The package uses your normal shadPS4 profile. It contains no games, firmware,
saves or creations. Keep the extracted folder together. Existing portable
profiles are not moved automatically.

If a tutorial blocks progress, close Dreams and open
tutorial-skip/Skip Dreams Tutorial.exe. Select your own CUSA04301/SYSTEM/
savedata.json. The helper makes a backup before changing progression flags.
